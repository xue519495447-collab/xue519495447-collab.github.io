# 薛博 · 摄像剪辑师 · 求职作品集

深色影院风的个人作品集网站。纯 HTML + CSS + JavaScript 手写，**不需要安装任何软件、不需要构建工具**，双击 `index.html` 就能在浏览器里预览。

## 文件结构

| 文件 / 文件夹 | 作用 |
| --- | --- |
| `index.html` | 首页（第一屏循环播放三部王牌片段、精选作品、能力、联系方式） |
| `works.html` | 作品列表页（13 张卡片 + 六类筛选） |
| `about.html` | 关于我（照片、经历时间线、设备清单） |
| `work-01.html` ~ `work-13.html` | 13 个作品详情页（按清单顺序编号） |
| `work-template.html` | **新作品页模板**：复制改名就能加新作品，内含步骤说明 |
| `style.css` | 全站外观。换主题色只改顶部 `--accent` 一个值 |
| `main.js` | 交互（手机菜单、进场动画、微信复制、作品筛选、首屏轮播） |
| `assets/` | 图片：`thumb-XX.jpg` 卡片缩略图、`poster-XX.jpg` 播放器海报、`hero-poster.jpg` 首屏海报、og-cover、favicon |
| `videos/` | **压缩后的视频**（总 446MB）：`work-01~13.mp4` + `hero-1~3.mp4` 首屏片段 |
| `raw/` | 原始 MP4 素材临时存放处（不会上传到网站；桌面的原片在「作品原片」文件夹） |
| `resume/xuebo-resume.pdf` | 简历（一页，与网站同风格，站点上可直接下载） |
| `gen-pages.py` / `process-videos.sh` | 生成脚本：改了作品清单后可重新生成详情页和列表页 |

## 视频怎么放

1. 原片丢进 `raw/` 文件夹，由 AI 用 ffmpeg 压缩成网页友好的 H.264
2. 压缩后的文件放进 `videos/`，按作品命名：`work-01.mp4`、`work-02.mp4`……
3. 首屏循环片段命名：`hero-1.mp4`（想轮播多条，在 `main.js` 顶部的 `HERO_LIST` 数组里加 `videos/hero-2.mp4` 等）
4. 详情页里视频就自动播放了；横屏长片放 60 秒内精选片段，完整版面谈播放

## 如何改文字内容

用记事本或 VS Code 打开对应 `.html` 文件，搜索"待替换"或"示例"字样，改成真实内容即可。每段代码旁都有中文注释标明这是哪一块。加新作品：复制 `work-template.html` 改名，再到 `works.html` 复制一张卡片改链接。

## 如何上线（GitHub Pages，免费）

> 为什么是 GitHub Pages：它是唯一"免费 + 支持视频拖动播放（HTTP 206）+ 单文件可到 100MB + 国内多数地区能打开"的托管。EdgeOne Pages 的免费域名对国内访客直接 401（官方文档），Cloudflare Pages 不支持 206 会导致微信/iPhone 里视频放不出来——都排除了。

1. 注册 [GitHub](https://github.com) 账号
2. 右上角 `+` → `New repository`，仓库名填 `你的用户名.github.io`
3. 仓库页点 `uploading an existing file`，把 `portfolio` 文件夹里的**全部内容**拖进去（注意是文件夹里的东西，不是文件夹本身），点 `Commit changes`
4. 等一两分钟，访问 `https://你的用户名.github.io` 就能看到网站 ✨
5. 以后更新：进仓库点开文件 → 铅笔图标编辑 → 保存；或重新上传覆盖

上线前会先用你的电脑实测 `github.io` 的连通性（国内个别运营商偶尔抽风）。如果以后想更稳，花 ¥60–100/年 买个自定义域名绑上去，国内解析会顺畅很多。
